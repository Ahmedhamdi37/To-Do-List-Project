# To-Do List Project

A simple and efficient task management application for organizing daily tasks and priorities.

## Overview
This is a straightforward to-do list application that helps users manage their tasks effectively with an intuitive and user-friendly interface.

## Features
- Add new tasks
- Mark tasks as complete
- Delete tasks
- Task filtering (All, Active, Completed)
- Local storage persistence
- Responsive design
- Clean user interface

## Technologies Used
- JavaScript
- HTML5
- CSS3
- Local Storage API

## Getting Started
1. Clone the repository
2. Open `index.html` in your web browser
3. Start adding your tasks

## How to Use
1. **Add Task**: Type in the input field and press Enter or click Add
2. **Complete Task**: Click the checkbox to mark task as done
3. **Delete Task**: Click the trash icon to remove a task
4. **Filter Tasks**: Use filter buttons to view different task states

## Features in Detail
- **Local Storage**: Your tasks persist across browser sessions
- **Responsive**: Works on desktop, tablet, and mobile devices
- **Real-time Updates**: Instant feedback on task actions
